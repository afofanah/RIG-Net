# RIG-Net paper (IEEE conference format)

Build: `pdflatex rignet.tex && pdflatex rignet.tex` (two passes for cross-references).
Requires IEEEtran.cls v1.8b (included). Bibliography is inline (`thebibliography`), no BibTeX needed.

Files: `rignet.tex`, `fig_arch.tex` (Fig. 1), `fig_fusion.tex` (Fig. 2), `fig_rollout.tex` (Fig. 3), `IEEEtran.cls`, `figs/phase.pdf`, `figs/horizon.pdf`, `rignet.pdf` (8 pages),
`paper_numbers.json` (every number in the paper, generated by `../ebola_gnn/paper_results.py`).
